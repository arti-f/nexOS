Ini adalah **NexOS Dashboard** — versi yang jauh lebih kompleks dan profesional.

Fitur yang tersedia:
**UI & Estetika**
- Tema dark premium dengan aksen cyan/neon
- Tipografi `Syne` + `JetBrains Mono` untuk tampilan professional
- Top bar global dengan search, status sistem, dan akses cepat

**Panel & Data**
- 4 stat cards real-time (CPU, RAM, Storage, Uptime) dengan indikator tren
- Resource utilization bars dengan 5 metrik sekaligus
- CPU sparkline chart yang bergerak live setiap 1.2 detik
- Top processes dengan mini progress bar
- Network interfaces table dengan kecepatan download/upload

**Service Management**
- Grid 6 service dengan status indicator (online/warning/offline)
- Uptime history 90 hari bergaya GitHub contribution graph

**Navigasi Sidebar**
- Kategorisasi lengkap: Overview, Applications, Storage, Network, Security
- Badge notifikasi di setiap section

**Event Log**
- Recent system events dengan color-coded severity (info, warning, error, success)
